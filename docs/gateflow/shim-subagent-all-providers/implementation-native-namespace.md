Unrelated MCP/functions/Code Mode descriptors, structured unrelated choices, unknown input history and every other field survive. Scoped mapped-name declaration collisions, unsupported selected wrappers and structured native choices fail fixed sanitized 400 before upstream send. Namespace group labels are not bare callable declarations; their known children are inspected. No arbitrary-schema recursion, aliases, global/session lookup, model/policy/catalog forcing or speculative future-prefix checks were added.

Response restoration only adds the advertised namespace to mapped function_call objects when absent/null, at SSE added/done/completed.output and JSON.output. Explicit different namespaces abort without overwrite. Arguments/name/call_id/id/status/extensions remain exact. Incremental real SSE framing supports arbitrary chunks, UTF-8, CRLF/LF/CR, multiple data lines and raw non-target/comment/delta preservation; it buffers one event, bounded at 8 MiB, also the nonstream JSON bound. Controlled actual-handler tests prove read1 first-event delivery before upstream EOF and concurrent different maps for the same bare name.

An active nonempty map accepts only absent/identity success Content-Encoding and SSE/JSON media; unsupported success encodings fail sanitized 502 before downstream headers. Existing connection-close transport removes stale length/hop-by-hop and Connection-nominated headers. Malformed/truncated/oversize/conflicting streams close without adapter retry, synthetic terminal or midstream HTTP 400. Active-map non-2xx buffered error data is forwarded with its original status; flags-off/empty-map non-2xx behavior stays identical to the saved baseline. Guardian buffering/retry, original per-request private endpoint/auth/model snapshot, prefixes, ID/JSON/drop/Lite/custom behavior remain covered by focused tests.

The generic probe observes actual post-agent-message/native-request/subsequent stages and final send hash, exact descriptor location, actual response pre/post bytes/hashes, mapped native-call pairs and namespace counts, encoding/content headers and first-body/EOF timing. Full responses are hashed incrementally; retained raw SSE is limited to mapped native added/done events, while completed events retain native call projections/hashes without hidden reasoning. Launch source hashes have retrievable snapshots. Captured JS is never executed. The sanctioned resolver alone reads private settings for actual routing; no credentials/private URLs/raw private config are printed or edited.
