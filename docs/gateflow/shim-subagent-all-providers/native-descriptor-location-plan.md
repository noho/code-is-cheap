## Concrete evidence and decision

- [MiMoFlash namespace A1 wire](evidence/mimo-flash/namespace-scenario-a-attempt-1/wire.json) has 18 requests; [B1 wire](evidence/mimo-flash/namespace-scenario-b-attempt-1/wire.json) has 5. Every request advertises exactly one native `collaboration` wrapper at `input[0].tools[2]`, in an input item of type `additional_tools`; selected top-level native tools are absent. Its six actual function children include `spawn_agent`, `followup_task`, `send_message` and `wait_agent`.
- `native_request_stage` records `flatten=false`, `map={}`, `before_tools=null`, identical before/after hashes. [Implementation report](implementation-native-namespace.md) records zero MiMoFlash restorations. An enabled response flag and successful old B do not establish activation of the repair; the prior bare-wait defect is not proved fixed on actual Lite advertisement.
- This is a necessary compatibility correction for an observed current protocol location, not speculative future descriptor discovery. Permit that location for **response-only mapping**, preserving the entire request. No new flag is justified.

## Narrow implementation contract

1. **Request-flatten path (`flatten=true`, Kimi): top-level only.** Keep current selection, validation, collision rules, wrapper flattening and response map semantics. Never flatten or derive restoration entries from input `additional_tools` on this path. Existing additional-tools collision inspection remains.
2. **Response-only path (`flatten=false`, MiMoFlash): two known sources.** Collect selected wrappers from current HTTP `tools[]` and `input[i].tools[]` only when that immediate input item has exact `type="additional_tools"` and an array `tools`. Do not hardcode index 0/2, recurse through arbitrary objects, parse text, inspect schemas for names, or reconstruct tool activation across history items/requests.
3. In both sources select only exact `type="namespace"`, name `multi_agent_v1` or `collaboration`, and their actual advertised function children under the accepted descriptor-shape rules. Native wrappers are not MCP groups. Preserve opaque child fields and readable extra response-only wrapper metadata; unsupported selected-native structure fails sanitized 400 before upstream.
4. Missing/non-array top-level `tools` must not cause an early return before checking the known additional-tools source on the response-only path. This change alone does not validate or rewrite unrelated malformed/unknown descriptors. No selected callable means empty map and the existing passthrough response path.
5. Construct the same immutable per-request bare-name → namespace map, discard at request end. Return the original body bytes on the response-only path, including lexical whitespace/order. This identity is at the native stage; existing independent stages and supported compression boundaries retain their contracts. Never reserialize merely to collect a map.
6. Validate selected declarations together, then collision-check their mapped names against **other** declared callables in both known sources under the accepted scoped rules. Exclude every selected wrapper occurrence from that second scan, so an additional-tools native group does not collide with itself. Namespace group labels are not callable names; their nonselected known children still count. Unrelated duplicates and unknown unrelated/nameless descriptors pass unchanged; an unknown explicit declaration-level mapped name fails.
7. **Duplicate rule:** retain conservative rejection of repeated selected native callable declarations, including identical repeats in one/across containers. Actual A1/B1 has one native wrapper per request and supplies no need for repeated-activation semantics; identical repeats are explicitly unsupported, not silently deduplicated. Same bare name mapped to different native namespaces, conflicting schema/metadata duplicates, and nonidentical repeated declarations all fail sanitized 400 before upstream, with zero upstream calls. Disjoint unambiguous native declarations may contribute to one map. No first/last-wins, historical version resolution or new activation state. A newly observed required repeat needs a bounded contract decision.
8. Nonselected tools, all input/history, choices, instructions and other request fields remain unchanged. Guardian bypass, current flag defaults/route scope, seven flags-off routes, catalogs, policies, Lite/Code Mode, and existing response/SSE/error contracts remain unchanged. No aliases, global state, general descriptor adapter, MCP flattening or argument repair.
