## Findings

### 1-未修复-[低]-Claude 根 assistant 空文本帧清除已保留的根 partial display，并连带丢失其 canary 证明归因

- **入口/函数**: `Collection.claude()` 根 assistant 文本更新路径（`scripts/agent-run-result.py:364-372` 文本块收集 + `:400-402` 赋值），经 `collect()`/`main()` 出现在 report 的 `final_answer`/`final_answer_chars` 与 `check_proofs(self.final…)` 归因。
- **文件(行号)**: `scripts/agent-run-result.py:400-402`（条件 `if kind == "assistant" and root and text:` 对**列表**取真值）+ `:364-372`（`text.append(block["text"])` 接受空字符串）。
- **输入场景**: 可读 partial（如 `"partial root"`）之后出现一个 root assistant 帧，其 text 块全部为空串（`[{"type":"text","text":""}]`，含与 tool_use 并列的空文本块形态）；此后没有可读的权威 result（缺失 / 非字符串 / 空白 result）。
- **实际分支**: `text == [""]` → 列表非空取真 → `self.final = "".join(text) == ""` → 覆盖先前 partial；`final_valid` 仍为 False，拒收路径不变。
- **预期行为**: 按 `plan-v2.md` §Claude root identity/final 第 3 条与 DS-A1 裁决（"无可读 result 文本时保留先前 root 文本作 partial display，同时保持拒收"），不可读的空文本不应清除可读 partial；display 保留、拒收照旧。
- **实际行为**: `final_answer`/`final_answer_chars` 被清空为 `""`；且 `check_proofs` 扫描 `self.final`，partial 内的 canary 证明随之丢失：`canary_status` match→mismatch 并新增 `missing standalone canary report` 错误；mismatch 场景丢失精确归因（`canary proof does not match expected token`）。
- **直接证据**: 本轮独立差分 probe（base `8a0be0d0` vs head `aa9b1a3e`，合成输入，记录于 `evidence/pr-ds-flash/probe-empty-assistant-text/summary.json` 与 `summary-canary.json`）：
  - A（无 result）/ B（result=42，非字符串）/ F（空文本+tool_use 并存）: base display `'partial root'` → head `''`；
  - G（partial 携带匹配 token）: base `canary=match` → head `canary=mismatch` + `missing standalone canary report`；
  - G2（partial 携带错误 token）: base 有精确 mismatch 归因 → head 归因丢失；
  - 控制案 C（有效 result）、D（tool-only 帧）、E（空+非空文本）两版行为一致。
  代码路径同一数据链：`:372` 追加空串 → `:400` 列表真值 → `:401` 覆盖 `self.final`（此前由 `:400-402` 或 DS-A1 修复后的 `:344-347` 保留）。两版 exit/validation 均为 1/rejected（B 中 base 的 `agent_status=completed` 恰是 S-1 已修复的旧证明缺陷，非本 finding 目标）。
- **影响**: 仅诊断展示/归因层（`final_answer`、`final_answer_chars`、保留文本上的 canary/诊断归因）；不改变 call acceptance、退出码、`validation_status`/`agent_status` 判定或 `result_status=not_assessed`。拒收调用中可读 partial 的可见性降低，与 DS-A1 同类族（该 gate 曾对同类空白覆盖要求修复）。
- **建议改法和验证点**: 将 `:400` 的列表真值改为对 join 结果非空判断（保持 root 限定），例如 `joined = "".join(text); if kind == "assistant" and root and joined:`；补回归：`[partial, assistant([""]), 无 result 或非字符串 result]` 断言 display 保留与 canary 归因（可并入 `test_claude_result_owns_final_without_assistant_fallback` 或 canary 矩阵）。验证点：A/B/F/G/G2 五案 + 全量 56 + 受影响 targeted 复评。
- **修复风险（低）**: 单行条件收紧；需确认不改变控制案 C/D/E 行为（空后非空仍取新文本、tool-only 帧不触达赋值）。
- **严重程度（低）**: display-only 回归；触发帧结构有效但未在任何 native 记录中直接观察（触发真实性受限，修复与否由 controller 裁决），验收/退出契约不受影响。
