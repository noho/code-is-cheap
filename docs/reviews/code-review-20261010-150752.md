### 1-未修复-[中]-结果适配器把数值溢出写成非标准 JSON 并误报通过
- **入口/函数**: `agent-run-result.py` collected-mode entry through `main()` -> `Collection.collect()` -> `terminal_metrics()` -> report serialization
- **文件(行号)**: `scripts/agent-run-result.py:141`, `scripts/agent-run-result.py:146`, `scripts/agent-run-result.py:153`, `scripts/agent-run-result.py:264`, `scripts/agent-run-result.py:382`
- **输入场景**: runtime JSONL contains a syntactically accepted but numerically overflowing terminal metric, for example `{"type":"turn.completed","usage":{"input_tokens":1e400}}`; the same path accepts overflow values nested in Claude `modelUsage`
- **实际分支**: `json.loads` converts `1e400` to positive infinity, `terminal_metrics()` copies the usage/modelUsage object without recursive finite-number validation, `collect()` records no error, and default `json.dumps` serializes the value as `Infinity`
- **预期行为**: malformed/non-finite runtime metric data must be treated as invalid or unavailable, and runner stdout must always be standards-compliant JSON with an explicit diagnostic
- **实际行为**: a private synthetic reproduction returned `validation_status="passed"`, `runner_exit_code=0`, and `usage={"input_tokens": Infinity}`. Strict JSON consumers reject that report even though the runner reports success
- **直接证据**: `scripts/agent-run-result.py:264` uses unrestricted `json.loads`; `:146` and `:153` retain raw dictionaries; `:382` uses `json.dumps(..., ensure_ascii=False)` with default `allow_nan=True`. `tests/test_agent_run_results.py:125` covers non-object usage and the literal `NaN`, but not finite-width numeric overflow such as `1e400`
- **影响**: Agent-facing result parsing can fail after a successful run, metrics become non-interoperable, and malformed runtime data is silently accepted as `passed`; downstream automation may lose the final answer while parsing the report
- **建议改法和验证点**:
  - Reject non-finite numeric tokens during event parsing or recursively validate all retained `usage`/`runtime_metrics` values before copying
  - Serialize the report with `allow_nan=False`, mapping unavailable/malformed metrics to `null`/empty values and recording an anomaly or error according to the chosen contract
  - Add runner/result-adapter tests for `1e400`, `-1e400`, nested overflow values and serialization through a strict JSON parser
- **修复风险（低/中/高）**: 低
- **严重程度（低/中/高/严重）**: 中
