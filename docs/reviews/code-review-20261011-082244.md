## Open Questions

- 无阻塞性问题。两点边界观察以假设形式记录（均为 accepted A1 定义的既定语义，非缺陷）：
  - 观察 1：`-----BEGIN CERTIFICATE----x` / `-----BEGIN CERTIFICATE X`（≤4 连字符后接非空白字符 / 空格后缀长标签）在伴随合法证书时被按“长标签周边文本”忽略（实测 pass），单独存在时仍以 `no certificate blocks` 失败。这是 adjudication 明示的分类（“hyphen/space-suffixed longer labels are not certificate labels”）；其与 native PEM parser 的最终语义差异属于既有的 runtime-upgrade-owned parser-equivalence 残余风险，且 wrapper 不会为这类块授予任何信任（native 仍消费原文件，native 拒绝会保留真实运行失败）。
  - 观察 2：首行含 BOM 的包会因 BEGIN 被忽略而落到 `orphan certificate END`（同样失败，仅 reason 与 pre-fix 的 malformed 不同）；方向为 fail-safe。
- native 对 CSR/长标签组合的接受度、以及准确的被阻断 macOS 服务，均保持 UNMEASURED（本 review 不做也不重复任何此类声明）。
